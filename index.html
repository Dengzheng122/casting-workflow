熔铸仿写工作流

转帖来源：阿北 @abeicode · 原仓库 dama-cyber/Casting-Workflow · 许可 MIT

从多篇同类型小说中提炼风格指纹，再由 LLM 生成番茄风短篇，带后处理与质量审计。本地 Python 管道，不是网页一键生成器。

用法（4 步）

  1. Step 0 · 准备语料：把同类型小说 .txt（每类 ≥5 篇）放入对应分类目录。9 个标准分类：现代言情、总裁豪门、重生复仇、穿越架空、古代言情、玄幻仙侠、悬疑惊悚、甜宠虐恋、种田经商。
  2. Step 1 · 蒸馏指纹：
    python run_pipeline.py --category 05_古代言情
    扫描语料 → 剔除损坏文件 → 随机选 5 篇提取指纹（人物 / 情节 / 句式 / 高频词）取交集互消 → 输出 output/fusion_context.txt。
  3. Step 2 · LLM 生成故事：把 fusion_context.txt 全部内容原封不动复制给 LLM（Claude / GPT / DeepSeek 均可），生成约 1000 字的原创短篇，保存为 output/story.txt。
  4. Step 3 · 后处理：
    python tools/clean_commas.py output/story.txt
python tools/inject_punctuation.py output/story.txt --excl 0.15 --comma 1.2
    清理脏逗号，按密度注入标点，模拟番茄小说风格。
  5. Step 4 · 质量审计：
    python check_story.py output/story.txt
python tools/audit.py output/story.txt corpus/05_古代言情/*.txt
    9 项爆款规则自动检测 + 独创度审计（对比源文，确保 0 复制；朱雀 16 字扫描 vs 全部 5 篇源文 → 0 匹配）。

进阶：12 阶段提示词模式

用 --stage 切入单个创作阶段精细控制，-P 可链式传递前序阶段输出：脑洞 → 灵感风暴 → 人设 → 大纲 → 细纲 → 概要 → 开篇 → 正文 → 优化 → 润色 → 续写 → 扩写。

python run_pipeline.py -s 脑洞 -c 05_古代言情
python run_pipeline.py -s 人设 -c 05_古代言情 -P output/脑洞_output.txt
运行前提：本地 Python，pip install -r requirements.txt（仅 jieba 分词库）。按原仓库 FAQ：不需要 API 密钥；生成故事那步需自己把上下文贴给 LLM。语料需自备，本部署站不含任何小说原文。
